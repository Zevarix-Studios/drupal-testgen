# Security Policy

## Supported versions

TestGen has not released a stable version yet. Security fixes currently target the active development line.

## Reporting a vulnerability

Please do not publish exploit details, credentials, sensitive Drupal configuration, or other secret material in a public issue.

If GitHub private vulnerability reporting is available for this repository, use that channel. Otherwise, open a public issue containing only a request for private maintainer contact and enough non-sensitive context to route the report; do not include vulnerability details until a private channel is established.

Reports involving accidental secret exposure should identify the affected path or artifact without repeating the secret itself.
